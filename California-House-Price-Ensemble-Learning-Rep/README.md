# California Housing Ensemble Learning

## Project Overview

This project demonstrates regression-based machine learning techniques for California housing price prediction.

The project implements a Decision Tree Regressor as a baseline model and compares it with different ensemble learning techniques.

The following models are implemented:

1. Decision Tree Regressor
2. Bagging Regressor
3. Gradient Boosting Regressor
4. Random Forest Regressor

The main objective is to understand how ensemble learning methods can improve regression performance by combining multiple decision trees.

---

## Objective

The objective of this project is to:

- Load and analyze the California Housing dataset.
- Separate input features and target variable.
- Split the dataset into training and testing sets.
- Train different regression models.
- Generate predictions on test data.
- Evaluate model performance.
- Understand the difference between a single Decision Tree and ensemble learning techniques.
