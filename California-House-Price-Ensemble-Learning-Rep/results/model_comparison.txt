Models are built one after another. Each new model attempts to

Improve prediction performance by sequentially correcting errors.

6. EVALUATION METRICS
---------------------


A. MEAN SQUARED ERROR (MSE)
---------------------------

MSE measures the average squared difference between actual and
predicted values.

Formula:

                 n
MSE = 1/n × Σ (Yi - Ŷi)²
                i=1

Where:

Yi = Actual value
Ŷi = Predicted value
n  = Number of observations

Interpretation:

Lower MSE = Better performance

Higher MSE = Larger prediction errors


B. R² SCORE
-----------

R² Score measures how well the model explains the variation in
the target variable.

Formula:

              Σ(Yi - Ŷi)²
R² = 1 - --------------------
              Σ(Yi - Ȳ)²

Where:

Yi = Actual value
Ŷi = Predicted value
Ȳ  = Mean of actual values

Interpretation:

Higher R² = Better performance

R² closer to 1 = Better model performance

R² closer to 0 = Weak explanatory power

9. SINGLE MODEL VS ENSEMBLE MODELS
----------------------------------

Decision Tree:

Uses one Decision Tree.

Advantages:

- Simple
- Easy to understand
- Easy to implement

Disadvantage:

- Can overfit the training data.


Bagging:

Uses multiple Decision Trees trained independently using bootstrap
samples.

Main goal:

Reduce variance.


Gradient Boosting:

Builds models sequentially where each new model attempts to correct
the errors of previous models.

Main goal:

Improve prediction by reducing errors.


Random Forest:

Uses multiple randomized Decision Trees and combines their
predictions.

Main goal:

Reduce variance and improve generalization.

12. RANDOM FOREST VS BAGGING
----------------------------

Both Random Forest and Bagging can use multiple Decision Trees.

Bagging:

- Uses bootstrap samples.
- Base estimator is explicitly provided in this project.
- Combines predictions of multiple estimators.

Random Forest:

- Uses multiple Decision Trees.
- Uses bootstrap sampling.
- Adds random feature selection.
- Provides additional randomness between trees.

Therefore:

Random Forest can be considered a specialized tree-based
ensemble approach with additional feature randomness.
